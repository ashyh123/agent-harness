# Jev 独占分类：完整流程对照

2026-10-11。结论：职责已移交，效果持平，但未证明降低全流程成本或耗时。保留实验入口，不自动改默认配置。

## 真正移交了什么

Python 提交 schema 使用不含 capability/complexity 的 CenterSubmissionDraft，额外字段被拒绝。独占模式下协调 Skill 不再要求 DeepSeek 判断分类或建议执行端；它负责目标、信息充分性、任务拆分、验收和用户指定的 route。Jev 使用既有外壳/工具能力上下文产生分类后才进入原路由器，DeepSeek 继续读取和审阅结果。分类失败不提交，不以缺省分类偷偷回退。原 jev 模式仍可选，保留主模型分类作为回退。

逐条查看12次新方案的真实submit_tasks参数，均不含两个分类字段。此证据验证了接口和行为契约，不证明模型内部完全没有进行语义分类思考。原模型仍要生成提交调用，因此不应预期必然减少一次请求。

## 实验控制

同样四项任务（计算、内联JSON汇总、博客故障恢复阅读、Python JSON→CSV）各三轮，每组12项，共24条完整流程；交替执行顺序。与上一批用同一任务清单，但单独重新跑原方案对照，不混用旧批次均值。模型、工具、预算、真实主模型审阅、升级规则相同。区别仅为新方案提交schema/协调指令职责分离与Jev补齐分类。主Agent仍可能生成不同任务措辞与验收条件，这是完整系统实验的波动源，不是固定执行trace回放。

DeepSeek沿用deepseek-flash，Jev固定jev-1.13.0，Codex使用相同本机CLI配置；主Agent每轮model12/tool16/180秒、原任务及worker预算不变，整个入口900秒。Codex内部循环不是由DeepSeek请求预算限制。四类任务各三次不能当作12种独立任务，所有任务复杂度在本批均为simple，不代表复杂规划能力。

## 验收与金额口径

额外产物检查在任务完成后运行，不干预原主Agent审阅：计算385；合计72/均值24/最大36；CSV前导零004/009、原顺序、统计36/18/2及成功Python执行日志；博客主要引文匹配既有正文快照，并核查session日志恢复与条件性沙箱重建。程序匹配不等于任意文章解释正确，验收范围仅本批问题。

费用包含全部主Agent、DeepSeek worker和Jev可观测API用量，失败与升级消耗计入；缓存命中按对应价格估算。Codex只有token用量，实际账单未知，绝不按零计；因此不声称已测得总成本。价格沿用2026-10-11周日非高峰官方标价：[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/) / [Jev](https://docs.typesafe.ai/models)。
