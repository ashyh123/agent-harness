# 博客收录学习 Demo：本版收尾

验收日期：2026-10-11。目标是可运行、可解释、可验收的学习与简历项目。这一版的常规入口是固定 LangGraph 工作流；保留共享 LangGraph Agent loop 处理自主回查与修正。

## 完成范围

- 读取公开博客的有界正文，保存 Markdown/text 快照及来源 ID。
- 使用 DeepSeek 和 AI SDK 生成快速摘要、个人推论，并用候选编号选择原文证据。
- 引文候选长度取自保存工具 schema，合法213字符引文不会因内部200字符规则被拒绝。原文由程序复制，模型不能自行拼接。
- 保存前独立核对事实、核心结论与引文支持关系，以及绝对说法；片段真实性和风险项覆盖由程序检查。
- 实际写入专属 Obsidian vault，回读核验来源、字段和 SHA-256 收据。
- 共享预算包含核对、工具和上下文维护；读取、核对、参数、服务或预算失败时明确停止。

模型结束、文件保存和内容准确分别判断。原文快照不代表模型读过全文；本版没有增加新的框架、RAG或工具。

## 复现

在本机配置 `.env` 和专属 Obsidian vault，进入 `vercel_agent`：

```sh
npm run verify:blog-workflow -- --prepare
# 使用准备命令输出目录中的manifest.json；快照保留在本机
npm run verify:blog-acceptance -- /absolute/path/to/manifest.json
```

准备阶段抓取公开网页，失败时仅可用同URL已有快照；没有快照则失败。验收使用冻结资料调用真实模型并写入隔离测试目录。自动结果的source_review初始为pending，需要逐条核对原文；不能只凭脚本退出码宣称准确。网页变动或服务波动时，重新运行的结果可能不同。

## 收尾边界与简历表述

这版满足学习 Demo 的停止标准：来源可追溯、已知关键错误已回归验证、文件真实保存、失败明确说明、可重复验收。后续扩展由新的实际任务驱动。

可写入简历：基于LangGraph与Vercel AI SDK实现博客收录工作流及可回查Agent执行模式，设计共享请求预算、原文快照、证据核对和Obsidian文件回读验收；通过三篇厂商博客的重复保存及错误证据回归测试。

不宣称生产级可靠性、任意长文无损阅读、普遍优于Agent loop或百分之百无幻觉。核对器依然使用同模型；绝对说法的关键词覆盖不等于完整语义分析。旧有笔记没有被自动纠正，长论文、动态网页、付费内容和外部分发不在本次验收范围。
